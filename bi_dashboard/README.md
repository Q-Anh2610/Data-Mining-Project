# BI Dashboard

Thư mục này lưu ảnh chụp dashboard BI của project ứng dụng chuyển ngữ Anh – Việt.
Dashboard được xây dựng bằng Apache Superset, sử dụng dữ liệu từ bảng `translation_history` trên Supabase.
Do dashboard BI được xây dựng trực tiếp trên Apache Superset nên phần này không có mã nguồn riêng. Nhóm lưu ảnh chụp dashboard và mô tả các thành phần trực quan hóa trong thư mục BI trên GitHub.

## Nội dung dashboard

Dashboard gồm các thành phần chính:

- Tổng số bản dịch
- Word Cloud thể hiện chủ đề người dùng quan tâm
- Tỷ lệ đánh giá bản dịch
- Thống kê trạng thái yêu thích
- Danh sách bản dịch mới nhất
- Xu hướng độ dài bản dịch theo ngày
- Biến động lượt dịch theo thời gian

## Mục đích

Dashboard giúp nhóm theo dõi dữ liệu lịch sử dịch, đánh giá sơ bộ hoạt động của hệ thống và hỗ trợ phân tích dữ liệu trong project môn Khai phá dữ liệu.
